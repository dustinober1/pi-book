# Novel Forge v1.7.1 — Release Workflow Consolidation

v1.7.1 is a CI-only patch. It changes no manuscript text, project schema, workflow state, or evidence content.

## Fixed

- Replaced the five version-pinned release workflows (`release-v1.3.yml`, `release-v1-4.yml`, `release-v1-6-1.yml`, `release-v1-6-2.yml`, `release-v1-7.yml`) with one `.github/workflows/release.yml` that reads the package version from `package.json` at run time.
- Cutting a future release no longer requires copying a new workflow file with the version hardcoded throughout; the same `release.yml` verifies and tags every release.

## Upgrade

Install from the pinned `v1.7.1` tag. This patch changes no manuscript text, project schema, workflow state, or evidence content.

# Novel Forge v1.7.3 — Decision-Ledger Event Boundary Guidance

v1.7.3 is a guidance-only patch. It changes no project schema, workflow state, or evidence content.

## Fixed

- `SKILL.md` now states explicitly that `series/decision-ledger.yaml` is never an allowed file for a `book-plan` event, even when the plan resolves author decisions (such as the four primary author decisions) as part of its reasoning. Decision-ledger evidence must go through its own prior `intake-update` (or, for a `historical-fiction` book, `research-update`) event, submitted before or alongside the `book-plan` event, not bundled into the `book-plan` file set.

This fixes a real failure mode: a `book-plan` submission that included `series/decision-ledger.yaml` in its changed-files bundle was rejected with `allowlist-violation`, and the workflow correctly stopped rather than retrying — but nothing was committed. The event-type file allowlists already enforced this boundary; the skill guidance now states it directly instead of leaving it to be inferred from a single numbered requirement.

## Upgrade

Install from the pinned `v1.7.3` tag. This patch changes no project schema, workflow state, or evidence content, so existing projects remain fully compatible.

# Novel Forge v2.2.1 — Release Verifier Consolidation

v2.2.1 is a CI-only patch. It changes no manuscript text, project schema, workflow state, or evidence content.

## Fixed

- Replaced 18 near-duplicate `scripts/verify-vX-Y-Z-release.ts` files and their 18 matching `tests/vX-Y-Z-release-checklist.test.ts` files with shared `check()`/`text()` helpers in `scripts/lib/release-check.ts`, a `scripts/lib/release-registry.ts` mapping each shipped version to its own preserved, byte-identical check function, one stable `scripts/verify-release.ts` CLI entry point, and one consolidated `tests/release-checklist.test.ts`.
- Every historical release's own frozen check function is preserved exactly as it shipped; only the boilerplate around it — the CLI runner and the `check`/`text` helpers — was shared. Each historical entry is still expected to report itself superseded against a later tree, not to pass.
- Cutting a future release now means adding one registry entry to `scripts/lib/release-registry.ts` and one new check file; `verify:release` and `test:release` never change again.

## Upgrade

Install from the pinned `v2.2.1` tag. This patch changes no manuscript text, project schema, workflow state, or evidence content.
